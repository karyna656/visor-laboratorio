# 🛡️ BioShield: Seguridad en Redes Médicas

Este repositorio centraliza herramientas de **Ciberseguridad** desarrolladas para proteger infraestructuras críticas de salud, combinando mi experiencia en **Bioimágenes** con programación segura.

## 🚀 Proyectos Destacados

### 1. Sistema de Prevención de Intrusiones (IPS) - `BioShield_Project`
Un sistema en Python que monitorea el tráfico de red en tiempo real para proteger equipos médicos (PACS, Tomógrafos).
* **Detección Anómala:** Identifica escaneos de red sospechosos.
* **Respuesta Automática:** Bloquea IPs atacantes tras superar el límite de seguridad (5 intentos).

### 2. Visor Seguro de Resultados
Aplicación web con principios de seguridad **SC-900**.
* **MFA:** Autenticación de doble factor.
* **Zero Trust:** Cada solicitud es verificada explícitamente.
